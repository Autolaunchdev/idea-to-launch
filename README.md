# Idea To Launch

AUTOLAUNCH — FULL PRODUCT EXPERIENCE



1. VISIÓN DEL PRODUCTO



Construye una aplicación web moderna, premium y funcional llamada Autolaunch, una plataforma de emprendimiento asistida por inteligencia artificial que transforma ideas de negocio en negocios funcionales.



La misión de Autolaunch es:



“Tu idea. Un negocio real.”



Autolaunch está dirigido a personas que tienen una idea de negocio clara, pero carecen de los conocimientos técnicos, el equipo o los recursos necesarios para ponerla en marcha.



El usuario explica su idea y Autolaunch le ayuda a convertirla en un negocio real mediante IA, agentes especializados, herramientas conectadas y automatizaciones.



No queremos crear simplemente otro chatbot, generador de páginas web o constructor de aplicaciones. Queremos representar un sistema que acompaña al emprendedor desde su idea hasta el despliegue y la operación de su negocio.



La visión a largo plazo es que una persona pueda crear y gestionar gran parte de su empresa mediante agentes de IA, manteniendo el control de las decisiones importantes.



Por ahora, construye un prototipo navegable que permita experimentar visualmente con el producto completo. Utiliza datos de demostración y simulaciones cuando una funcionalidad requiera servicios externos.



2. IDENTIDAD VISUAL



Crea una identidad visual tecnológica, minimalista, elegante y reconocible.



Colores



- Verde principal: #087F5B.

- Verde oscuro: #064E3B.

- Verde brillante de acento: #34D399.

- Fondo principal: #F8FAF9.

- Superficies: blanco.

- Texto secundario: #64736B.

Utiliza el verde como elemento principal de la identidad. Los fondos deben ser claros, con suficiente espacio en blanco, jerarquía visual y contrastes elegantes.



Incluye también una versión oscura de algunos paneles para representar la parte más tecnológica de la plataforma.



Logotipo



Crea un símbolo minimalista de un cohete ascendente integrado con una trayectoria orbital. Debe comunicar lanzamiento, progreso, autonomía y construcción.



Acompáñalo del nombre «autolaunch», en minúsculas, con tipografía sans serif moderna y contundente.



El logo debe funcionar en la barra lateral, la página de inicio, el favicon y los materiales de marca.



Tipografía y estilo



Utiliza una tipografía moderna similar a Inter.



Inspírate en productos SaaS premium como Linear, Stripe, Vercel y Notion, pero crea una identidad propia.



Utiliza:

- Bordes sutiles.

- Iconos lineales consistentes.

- Gráficos sencillos.

- Microinteracciones suaves.

Evita el aspecto de una plantilla genérica de IA. El resultado debe parecer una startup tecnológica seria y financiable.

1. Describe tu idea.

2. Diseña tu negocio.

4. Lanza y mejora tu negocio.

- Estrategia.

- Marketing.

- Ventas.

- Operaciones.

- Finanzas.

5. ONBOARDING: CONVERTIR UNA IDEA EN UN PROYECTO



Cuando el usuario pulse “Construir mi negocio”, inicia un asistente de configuración en varios pasos.



Paso 1: Tu idea



Pregunta:



- ¿Cómo se llama tu proyecto?

- Describe tu idea de negocio.

- ¿Qué producto o servicio quieres ofrecer?

- ¿Qué problema resuelve?

- ¿Qué te hace pensar que alguien lo compraría?



Paso 2: Tu cliente



Pregunta:



- ¿Quién es tu cliente ideal?

- ¿En qué país quieres operar?

- ¿Qué problema tiene?

- ¿Cómo lo resuelve actualmente?

- ¿Has hablado con posibles clientes?



Paso 3: Tu modelo de negocio



Pregunta:



- ¿Cómo vas a generar ingresos?

- ¿Cuál es tu precio estimado?

- ¿Venderás servicios, productos digitales, software o productos físicos?

- ¿Qué recursos tienes actualmente?



Paso 4: Tus recursos



Pregunta:



- ¿Cuál es tu presupuesto inicial?

- ¿Cuántas horas semanales puedes dedicar?

- ¿Qué conocimientos técnicos tienes?

- ¿Qué herramientas utilizas?

- ¿Trabajas solo o con un equipo?



Paso 5: Tu objetivo



Pregunta:



- ¿Qué resultado quieres conseguir en los próximos 30 días?

- ¿Qué consideras imprescindible para lanzar?

- ¿Qué no necesitas todavía?



Permite guardar el progreso, volver atrás y editar las respuestas.



Al finalizar, muestra un botón “Generar mi Blueprint”.



En esta demostración, la generación puede utilizar una plantilla y datos locales. Diseña la arquitectura para que en el futuro pueda conectarse a un modelo de IA real.

13. ANALÍTICA Y CONTROL DE COSTES



Esta sección es fundamental para el modelo económico de Autolaunch.



Queremos medir tanto la caja como el coste económico del trabajo.



Datos por proyecto



Incluye:



- Precio del Deployment.

- Ingresos cobrados.

- Costes de herramientas.

- Costes de APIs.

- Hosting y servicios externos.

- Horas de trabajo.

- Tarifa interna por hora.

- Coste económico del trabajo.

- Coste total de entrega.

- Margen de contribución.

- Costes de mantenimiento.

- Horas de soporte posteriores.



Fórmulas



Coste laboral imputado = horas trabajadas × tarifa interna.



Coste de caja del proyecto = pagos directos atribuibles al proyecto.



Coste económico de entrega = coste de caja atribuible + coste laboral imputado.



Margen de contribución = ingresos del proyecto − costes variables de entrega.



Muestra por separado los costes compartidos y evita contabilizarlos dos veces.



Registro de trabajo



Crea una tabla editable con:



- Fecha.

- Proyecto.

- Fase.

- Tarea.

- Horas.

- Herramienta.

- Coste de caja.

- Coste laboral imputado.

- Resultado.

- ¿Es reutilizable?



Permite añadir, editar y eliminar registros.



Dashboard de costes



Muestra:



- Coste de caja acumulado.

- Coste económico acumulado.

- Horas invertidas.

- Distribución del tiempo por fase.

- Coste por módulo.

- Incidencias y retrabajo.

- Componentes reutilizables.



Incluye datos de demostración y etiquetas que indiquen que no son datos financieros reales.

16. IMPLEMENTACIÓN TÉCNICA



Construye la aplicación con una arquitectura clara y componentes reutilizables.



Utiliza el stack recomendado por Lovable para crear una aplicación web moderna, responsive y mantenible.



Requisitos:



- Código modular.

- Componentes reutilizables.

- Datos de demostración separados de la lógica de presentación.

- Formularios funcionales.

- Navegación real entre secciones.

- Estado compartido entre pantallas cuando corresponda.

- Cálculos económicos implementados de verdad.

- Persistencia de datos de demostración.

- Preparación para integrar posteriormente un backend y modelos de IA.



No implementes conexiones bancarias, cobros reales, ejecución autónoma de agentes ni integraciones externas reales en esta primera versión.



No almacenes secretos ni claves API en el frontend.



No necesitas implementar autenticación real si eso dificulta crear el prototipo; puedes comenzar con un espacio de demostración y una sesión de usuario ficticia claramente identificada.
